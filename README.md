#  TEIWAZ
**Retro-style First-Person Shooter built from scratch in Python, inspired by Doom.**
## About the Project
**TEIWAZ** is a fast-paced, retro-inspired FPS game developed entirely in Python using Pygame.  
The project showcases custom raycasting, procedural world generation, and advanced game logic — all **without using any third-party game engines**.
---
##  Features
- **Custom raycasting engine** for pseudo-3D graphics (Wolfenstein/Doom style)
- **Procedural map generation** using Perlin noise
- **MySQL-powered stats and progress tracking**
- **Multiple weapon types** with unique mechanics
- **Custom menu/UI** (not stock Pygame widgets)

## Technology used
- **Python 3.10+**
- **Pygame** — rendering, input, sound
- **NumPy** — for procedural generation
- **MySQL** — persistent stats and save/load
- **Own codebase** — no Unity/Unreal/Construct/engines!
